## Call Script Structure

The AI voice agent follows this structure on every call:

1. **Opening** — Identifies as FleetTrack, confirms vendor, names specific crane and its current booking/status
2. **Operational Status** — Asks if the crane is working as expected
3. **Work Progress** — Asks what specific task is being done
4. **Issues / Maintenance** — Asks about any mechanical issues or upcoming needs
5. **Timeline** — Asks if work is on track for the booking end date
6. **Closing** — Thanks the vendor, confirms it will log the update

**Tone:** Professional, respectful, addresses vendor as "sir" or by name. Calls target 60-90 seconds.

**Architecture:** Currently using local LLM to generate transcripts. Ready for Twilio/Bland.ai integration — the `external_call_id` field tracks the provider's call SID, and a webhook endpoint can receive real transcripts on call completion.
